# Process Studio

Diagram, workflow, whiteboard, roadmap

Diagram flowcharts, workflows, org charts, ER diagrams, UML, BPMN, and architecture maps. Plan roadmaps, Gantt charts, and Kanban boards, map customer journeys and user flows, and manage CRM pipelines, SLAs, and policies.
